# PLC Dummy SDK

The PLC Dummy SDK is a stand-in for the PLC-36 SDK. It exists to exercise the
documentation, CI and contribution infrastructure on GitHub.

| Part | Role |
|---|---|
| [Debouncer](library/debouncer.md) | Filters contact bounce from a digital input |
| [Status LED](library/status-led.md) | Drives the board's status LED |

Start with [Environment Setup](environment-setup.md). The Shelly Host side of
the device is documented in the
[Shelly Gen2+ API](https://shelly-api-docs.shelly.cloud/gen2/).
